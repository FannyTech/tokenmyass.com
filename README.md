# tokenmyass.com

Site vitrine de **TokenMyAss** : *Before you ape… ask the Donkey.*

Site statique (un seul `index.html` + `assets/`), hébergé sur GitHub Pages avec le domaine `tokenmyass.com` (fichier `CNAME`).

## Langues
Anglais par défaut, français via le bouton EN | FR (ou automatiquement si le navigateur est en français).
Chaque texte existe en double dans `index.html` : `class="en"` et `class="fr"`.

## Vie privée
- Aucun cookie, aucun formulaire, aucune donnée personnelle collectée.
- Polices hébergées sur le site (`assets/fonts/`, licences OFL/Apache), pas d'appel à Google Fonts.
- Comptage des visites : GoatCounter (open source, sans cookie), tableau de bord sur https://tokenmyass.goatcounter.com
